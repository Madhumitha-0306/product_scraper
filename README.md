# Product Scraper

## SkillCraft Technology Internship – Task 4

A simple **Product Scraper developed using Python** that extracts product **names, prices, and ratings** from a webpage.

### Features

* Extracts product names
* Extracts prices
* Extracts ratings
* Displays the collected data

### Technologies

* Python
* Requests
* BeautifulSoup

### Run

```bash
pip install requests beautifulsoup4
python product_scraper.py
```
